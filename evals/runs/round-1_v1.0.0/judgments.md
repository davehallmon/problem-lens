# Blind Judgments — Round 1, version 1.0.0 (2026-10-03)

One judge agent per input. Each judge saw two responses labeled A and B, with the order randomized. The judges were not told which response used the Skill. The Skill output had its test-harness Turn 1 block removed. Skill run 1 was used for each input; it was not chosen for quality.

Scale: 1–5 per criterion, 35 maximum.

## Onboarding drop-off — A = baseline, B = Skill (run 1)

| Criterion | Baseline | Skill |
|---|---|---|
| Diagnosis | 5 | 3 |
| Option diversity | 4 | 4 |
| Actionability | 5 | 4 |
| Fit | 5 | 3 |
| Honesty | 4 | 4 |
| Decision support | 5 | 2 |
| Efficiency | 4 | 3 |
| **Total** | **32** | **23** |

Winner: baseline. Judge's main points:
- The baseline gives a test for each hypothesis.
- The baseline notes that 200 signups a week is too few for fast A/B tests.
- The baseline checks what "60%" actually measures.
- The Skill's anchor rationale ("Matches row 2") explains nothing.
- The Skill's lens columns add jargon without helping the user choose.

Skill-only strengths:
- Done-for-you setup as an option.
- A first-value test for step 3.

## Flat revenue — A = Skill (run 1), B = baseline

| Criterion | Skill | Baseline |
|---|---|---|
| Diagnosis | 3 | 5 |
| Option diversity | 4 | 4 |
| Actionability | 4 | 5 |
| Fit | 4 | 5 |
| Honesty | 4 | 4 |
| Decision support | 2 | 5 |
| Efficiency | 4 | 4 |
| **Total** | **25** | **32** |

Winner: baseline. Judge's main points:
- The baseline names five patterns that can produce a flat total, says how to tell them apart, and maps each to a response.
- The Skill's Coverage ranking is not tied to what the diagnosis finds.
- The Skill's anchor repeats row 1.

Skill-only strengths:
- A concrete one-day-a-week outreach owner.
- An add-on offer built from client interviews.

## Career decision — A = baseline, B = Skill (run 1)

| Criterion | Baseline | Skill |
|---|---|---|
| Diagnosis | 5 | 3 |
| Option diversity | 3 | 5 |
| Actionability | 4 | 5 |
| Fit | 5 | 4 |
| Honesty | 3 | 4 |
| Decision support | 5 | 3 |
| Efficiency | 4 | 3 |
| **Total** | **29** | **27** |

Winner: baseline. Judge's main points:
- The baseline names what the decision turns on and gives "leaning yes" and "leaning no" profiles.
- The Skill had the more varied and more concrete actions, such as testing the fallback with recruiters.
- The Skill's anchor rule was too crude.
- The Skill assumed the user has a partner.

## Totals

Across all three judgments:
- The Skill tied or beat the baseline on option diversity, actionability, and honesty.
