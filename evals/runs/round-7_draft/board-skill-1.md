**Summary**
The new idea at each meeting is a symptom; the likely root is that the board has no rule for deciding and no shared facts about why donations fell. Assuming staff keep donor records for the last two years, the board can find where the 15% drop came from before it picks a plan. Assuming the board chair can set the agenda and call a vote, the board can bind itself to one plan.

**What's Likely Going On**
- No decision rule: the board talks but never closes — check: do the minutes from the last few meetings show any motion or vote on a fundraising plan?
- No shared facts: each member argues from personal views because no one has seen why the 15% drop happened — check: can staff show which donors gave last year but not this year, and whether gift sizes shrank?
- No owner: ideas cost nothing to propose because no one has to run them — check: for past ideas, was anyone named to run them, and did any start? (Guess.)

**Recommendation**
- Do this first: Row 1 — pull the donor records and find where the 15% drop came from, because a plan built on the real cause ends the debate faster than another round of ideas.
- Switch to Row 2 if the minutes show the board has never held a vote on a plan, since then the gap is the decision rule, not the data.
